# Data Directory

In this directory, you can find:

- The 'images' directory; Where the following directories (test2017, train2017 and val2017) have all their respective images (.jpg files) can be found.

- The 'annotations' directory; Where all the .json files with the images information (instances, captions and person keypoints) can be found. Theres 'train2017' and 'val2017' files, the testing .json files are in the 'tests' directory.
